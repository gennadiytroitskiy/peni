# Расчёт пеней ЖКУ — ТСЖ/УК

## Запуск
```
pip install flask flask-login flask-sqlalchemy openpyxl fpdf2 werkzeug
python3 app.py
```
Откройте http://localhost:5000
Тестовый доступ: admin / admin123 (ОБЯЗАТЕЛЬНО смените пароль и SECRET_KEY перед реальным использованием)

## Что внутри
- peni_engine.py — ядро расчёта (FIFO-гашение, историческая ставка ЦБ, переход дедлайна 10→15)
- app.py — Flask-сервер: логины, БД (SQLite), импорт/экспорт Excel, PDF
- templates/ — HTML-страницы (вход, главная с формой расчёта)
- peni.db — база данных (создаётся автоматически при первом запуске)

## Что настроить под вашу организацию
В app.py, функция init_db() — замените:
- name_full, name_short, address, inn, ogrn (реквизиты ТСЖ/УК)
- данные пользователя admin (full_name, position)

Либо отредактируйте прямо в БД (таблицы organization, user) после первого запуска.

## Массовый расчёт
На главной странице загрузите реестр `.xlsx` с листами:
- `Начисления`: `Лицевой счёт`, `Период`, `Начисление, ₽`, необязательные `Срок оплаты`, `Вид долга`.
- `Платежи`: `Лицевой счёт`, `Дата платежа`, `Сумма платежа, ₽`.

Один ЛС группируется отдельно; его платежи применяются FIFO только к его начислениям. На один ЛС в текущей версии следует загружать один вид задолженности (ЖКУ либо капремонт). Есть образец в `static/template_mass.xlsx`.

**Важно:** импортируйте полные суммы начислений и историю платежей. Не подставляйте текущий остаток как сумму начисления одновременно с историческими платежами — это приведёт к повторному вычитанию платежей.

## Срок оплаты
Федеральный закон от 24.06.2025 № 177-ФЗ вступил в силу 01.03.2026: срок оплаты ЖКУ — до 15-го числа следующего месяца. Для срока, наступавшего до 01.03.2026, сохраняется прежнее правило до 10-го. Для начисления за февраль 2026 срок, таким образом, 15.03.2026. Официальная публикация: https://publication.pravo.gov.ru/document/0001202506240048

## Важно: ограничения текущей версии
1. Права доступа к истории расчётов пока ограничены текущим пользователем; управление пользователями через интерфейс не реализовано.
2. SECRET_KEY и демонстрационный пароль нужно заменить до реального использования; приложение не развёртывать с Flask debug-сервером.
3. Таблица ключевой ставки в `peni_engine.py` — демонстрационная историческая выборка, проверьте и дополните её по официальному архиву Банка России перед юридическим использованием.
4. Расчёт пеней, период применения ставки и распределение платежей требуют сверки с бухгалтерской и юридической методикой организации. Не используйте результат как судебный расчёт без проверки.
